# Sistema Avançado de Tarefas (CLI)

> Projeto desenvolvido para praticar e consolidar conceitos de Programação Orientada a Objetos (POO) em Java, aplicando manipulação de listas, encapsulamento e estruturas de controle.

## 🚀 Sobre o Projeto
Este é um sistema de gerenciamento de tarefas executado via linha de comando (CLI). O programa permite organizar o dia a dia criando tarefas com níveis de prioridade, controlando status de conclusão e filtrando pendências.

## 🛠️ Tecnologias Utilizadas
* **Java** (Estruturas de dados, List, Enum, LocalDate/LocalDateTime)
* **Git e GitHub** (Controle de versão e versionamento de código)
* **Eclipse IDE** (Ambiente de desenvolvimento)

## 📌 Funcionalidades
1. **Adicionar Tarefas:** Registo de descrições com definição de prioridades (`BAIXA`, `MEDIA`, `ALTA`).
2. **Listagem Completa:** Visualização de todas as tarefas cadastradas com os respetivos estados.
3. **Filtro de Pendências:** Exibição inteligente apenas das tarefas que ainda precisam de ser concluídas.
4. **Concluir Tarefas:** Atualização dinâmica do estado do item.
5. **Remoção de Itens:** Gestão e limpeza de registos da lista.

## 💻 Como Executar
1. Certifique-se de ter o **JDK** instalado no seu computador.
2. Clone este repositório ou descarregue os códigos da pasta `src`.
3. Importe o projeto no seu ambiente de preferência (como o **Eclipse**) e execute a classe `Program.java`.
